กระเป๋าเงินของฉัน — ชุดแอป PWA สำหรับ Android และ iPhone

ไฟล์ในชุด:
- index.html: ตัวแอป
- manifest.json และ icon-*.png: ข้อมูลและไอคอนสำหรับติดตั้ง
- sw.js: แคชไฟล์สำหรับการเปิดใช้งานแบบออฟไลน์หลังโหลดครั้งแรก
- README.txt: คู่มือฉบับนี้

ฟังก์ชัน:
- รายรับ/รายจ่าย พร้อมค้นหาและกรองรายการ
- สรุปยอดและกราฟรายเดือน
- งบประมาณรายเดือนแยกหมวด
- กระเป๋าเงินออมหลายใบ พร้อมเป้าหมาย ฝาก/ถอน และประวัติ
- ส่งออก CSV
- สำรองข้อมูลเป็น JSON และนำเข้ากู้คืน

การติดตั้งบน Android และ iPhone:
ต้องนำไฟล์ทั้งหมดขึ้นเว็บโฮสต์ที่ใช้ HTTPS ก่อน เพราะการเปิด index.html จากไฟล์โดยตรงไม่รองรับการติดตั้ง PWA และ Service Worker อย่างสมบูรณ์

วิธีทั่วไป:
1. สร้างเว็บไซต์แบบ static hosting ที่รองรับ HTTPS (เช่น GitHub Pages, Netlify หรือ Firebase Hosting)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ index.html อยู่ที่หน้าแรก
3. เปิด URL เว็บไซต์ที่ได้จากมือถือ

Android:
1. เปิด URL ใน Chrome
2. เปิดเมนู ⋮
3. เลือก Install app หรือ Add to Home screen
4. ยืนยันการติดตั้ง

iPhone:
1. เปิด URL ใน Safari
2. กด Share (ปุ่มแชร์)
3. เลือก Add to Home Screen
4. กด Add

การสำรองข้อมูลออนไลน์แบบใช้คนเดียว (ไม่ต้องสมัครสมาชิกในแอป):
เวอร์ชันนี้ใช้วิธีสำรองแบบไฟล์ เพื่อไม่ต้องเก็บข้อมูลการเงินบนเซิร์ฟเวอร์ของแอป และไม่ต้องตั้งค่าระบบบัญชีออนไลน์

สำรอง:
1. เปิดแอป > ตั้งค่า/สำรองข้อมูล
2. กด “ดาวน์โหลดข้อมูลสำรอง” จะได้ไฟล์ money-manager-backup.json
3. อัปโหลดไฟล์นี้ไปยังพื้นที่เก็บไฟล์ส่วนตัว เช่น Google Drive หรือ iCloud Drive
4. เก็บไฟล์ไว้ในโฟลเดอร์ส่วนตัว และไม่แชร์สาธารณะ

กู้คืนบนมือถือเครื่องใหม่:
1. ติดตั้ง/เปิดแอปบนเครื่องใหม่
2. ดาวน์โหลดไฟล์ JSON จากพื้นที่เก็บไฟล์ออนไลน์ลงเครื่อง
3. เปิดแอป > ตั้งค่า/สำรองข้อมูล
4. กด “นำเข้าข้อมูลสำรอง” แล้วเลือกไฟล์ JSON
5. ยืนยันการนำเข้า

ข้อควรระวัง:
- การสำรองแบบนี้เป็นแบบทำด้วยตนเอง ไม่ใช่การซิงก์อัตโนมัติ
- ข้อมูลในแอปแต่ละเครื่องแยกกัน หากต้องการให้บันทึกแล้วสำรองขึ้นคลาวด์เอง ต้องพัฒนาการเชื่อมต่อบริการคลาวด์และระบบสิทธิ์เพิ่มเติม
- อย่าล้างข้อมูลเว็บไซต์/เบราว์เซอร์ก่อนสำรองข้อมูล
- ไฟล์ JSON มีข้อมูลการเงินของคุณ ควรเก็บไว้ในพื้นที่ส่วนตัวที่มีการป้องกัน
- กระเป๋าเงินออมในแอปเป็นการจัดสรรยอดเงิน ไม่ได้เชื่อมบัญชีธนาคารจริง
